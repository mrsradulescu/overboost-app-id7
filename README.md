# OVERBOOST for iDrive 7 (MGU)

One app with a main menu: **M Vitals**, **Drag Timer**, **Fault Scanner**, **Engine Config**.
The logic comes from the open-source idrive7-apps project (MIT, `overboost-src/idrive7-apps`, which builds the iDrive 7 screens).

This repository is a **Store source** (mgu-store, "Repo tree" layout, see `docs/PUBLISHING.md` there): the car's Store installs
OVERBOOST from it and updates it when a new version is pushed here. The iDrive 8 version is a separate source:
`mrsradulescu/overboost-app-id8`.

## Install on the car (once)
1. The head unit needs the Store (mgu-store's installer, or the toolkit) and an internet connection.
2. Store -> **Sources** -> **Add source** -> GitHub -> `mrsradulescu/overboost-app-id7` -> channel **Branch: main**.
3. Open the new source, pick **OVERBOOST**, **Install**. The Store installs `app-privacy` and `mgu-render` first when they are
   missing, then builds the app on the unit against the oap-sdk of a stock BMW app (no BMW SDK file is in this repository).
   Restart the head unit if the tile does not show after a few minutes.

An OVERBOOST put on the car by the toolkit is the same app (same id `overboost`). It has no recorded origin, so the Store updates it
from the source whose listing has the same title (`OVERBOOST`): this one.

## Update
Push a new version here, the car's Store shows it under **Updates**. To publish one:
1. Change the code in `overboost-src/overboost/src` / `app`, raise `version` in `overboost-src/overboost/app/version.json`.
2. `python3 tools/store_tree.py` rewrites `apps/overboost/` (the source package the Store builds); `python3 tools/store_tree.py --check`
   says whether it is up to date. Needs Python 3.
3. Commit everything, including `apps/overboost/`, and push to `main`.

On a branch the Store compares **versions**: always raise the version.

## Layout
| Path | |
|---|---|
| `mgu-repo.json` | what the Store reads: one component, `overboost`, an app for iDrive 7 built on the unit |
| `apps/overboost/` | generated by `tools/store_tree.py`: `mgu-app.json`, the flattened modules, the staged package tree |
| `overboost-src/overboost/` | the app's sources (`src/`, `app/`) |
| `overboost-src/idrive7-apps/` | the idrive7-apps kit that builds the iDrive 7 tree (MIT) |
| `tools/store_tree.py` | the generator and its check |

## Fault Scanner texts
`overboost-src/overboost/src/dtc_db.pack` (~3.5 MB) is the fault-text database the Fault Scanner reads; it goes into the package
(`apps/overboost/package/javascript/`). Without it the Fault Scanner lists faults with their codes but shows texts only for the codes
in `known_texts.js`.

## Uninstall
Store -> OVERBOOST -> **Remove**.
